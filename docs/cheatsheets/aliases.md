# Aliases and functions

| Alias | Runs |
|-------|------|
| `fm` | yazi; on quit with `q`, the shell moves to the folder yazi was in (`Q` quits without moving) |
| `lg` | lazygit |
| `lzd` | lazydocker |
| `z` | zoxide: go to your most-used folder matching the words (`cd` stays plain) |
| `zi` | zoxide: pick from the matching folders with fzf |
