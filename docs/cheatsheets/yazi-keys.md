# yazi Keys

The keys worth remembering. `~` or `F1` inside yazi lists them all. Start yazi with `fm`.

| Key | Description |
|-----|-------------|
| `h` `j` `k` `l` | Parent folder, down, up, open folder |
| `gg` / `G` | Top / bottom |
| `Ctrl-U` / `Ctrl-D` | Half a page up / down |
| `Ctrl-B` / `Ctrl-F` | A page up / down. Inside herdr, `Ctrl-B` is the herdr prefix: use `PageUp` |
| `H` / `L` | Back / forward in folder history |
| `Enter` / `o` | Open |
| `O` | Open with |
| `Space` | Select and move down |
| `v` | Visual selection |
| `y` / `x` / `p` | Copy / cut / paste |
| `d` / `D` | Trash / delete permanently |
| `a` | Create a file (end the name with `/` for a folder) |
| `r` | Rename |
| `.` | Show or hide hidden files |
| `f` | Filter the folder |
| `/` / `n` / `N` | Find / next / previous |
| `s` / `S` | Search names with fd / contents with ripgrep |
| `z` / `Z` | Jump with fzf / zoxide |
| `cc` / `cd` / `cf` | Copy the path / folder / file name |
| `t` / `[` / `]` | New tab / previous / next tab |
| `;` | Run a shell command |
| `Tab` | File details |
| `q` / `Q` | Quit / quit without moving the shell |
